## 💔 你再熟悉不过的问题

> **"存储空间即将耗尽。"**

这条小小的提示毁掉一个个珍贵时刻。你正在拍摄孩子迈出的第一步——录像戛然而止。你正要拍下一张想珍藏一生的照片——相机却拒绝了。于是你打开相册，开始删除**回忆**，好为*新的*回忆腾出空间。这听起来很荒唐——因为它确实荒唐。

而且，这其实并不是你的错：

- 📸 每个应用都会重复保存你的照片：副本在无声中不断堆积。
- 🎥 一分钟的视频可能有**几百 MB**。多年的珍贵瞬间 = 让人恐慌的几十个 GB。
- 👯 重复文件：同一张照片被保存了五次（编辑版、转发件、连拍）。
- 📲 结果：应用无法更新，相机卡死，手机喘不过气来。

## ✨ Reducto 把这些空间还给你

一款目标明确的小巧 Android 应用，只有一个使命：**压缩你想保留的，清掉重复的，绝不弄丢任何一段回忆。**

- 🗜️ **真正的压缩** — 照片和视频大幅缩小，在你眼中依旧美丽如初。
- 🔍 **重复文件检测** — 完全相同的副本会被自动找出，等待你亲自确认。
- 📊 **清晰的仪表盘** — 准确看到能找回多少空间，并看着它随时间不断增长。
- 🛡️ **零风险删除** — 在动原图**之前**，压缩副本会先保存并校验完毕。没有你的确认，什么都不会消失。
- ⚙️ **后台运行** — 启动批量处理，去过你的生活，完成后收到通知。
- 🔒 **隐私至上** — 你的照片永远不会离开你的手机。一切都在你的设备上处理。
- 🚫 **无广告。无追踪。永远。**
