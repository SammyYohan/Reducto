## 💔 あなたがよく知っている問題

> **「ストレージの空き容量がわずかです」**

あの小さな警告が、大切な瞬間を台無しにします。子供が最初の一歩を踏み出すところを撮影していたら、録画が止まる。一生残しておきたい写真を撮ろうとしたら、カメラが拒否する。それでギャラリーを開き、*新しい*思い出のための場所を作るために、**思い出そのもの**を削除し始めるのです。不条理に感じられます——実際に不条理なのです。

そして、それは本当にあなたのせいではありません：

- 📸 あらゆるアプリが写真を再保存します：コピーは黙って積み重なる。
- 🎥 動画1分で**数百MB**になることも。積み重なった年月の瞬間 = パニックになるギガバイト。
- 👯 重複：同じ写真が5回も保存されている（編集版、転送されたもの、連写）。
- 📲 その結果：アプリは更新できなくなり、カメラは固まり、スマホは息をする間もなくなる。

## ✨ Reducto がその場所を取り戻します

ひとつの使命に集中した、小さな Android アプリ：**残すものは圧縮し、重複したものは削除し、道中でひとつも思い出を失わない。**

- 🗜️ **本物の圧縮** — 写真も動画も劇的に小さくなりながら、あなたの目には美しいまま。
- 🔍 **重複検出** — 同じ内容のコピーを自動で見つけ出し、あなたの確認を待ちます。
- 📊 **わかりやすいメーター** — どれだけの容量を取り戻せるか正確に見え、増えていく様子も分かる。
- 🛡️ **リスクゼロの削除** — 圧縮コピーの保存と検証が済んで**から**、初めて元のファイルに触れます。あなたの確認なしに何も消えません。
- ⚙️ **バックグラウンド動作** — 処理を開始したら、いつも通りに過ごし、完了したら通知を受け取る。
- 🔒 **プライバシー重視の設計** — 写真がスマホの外に出ることは決してありません。すべて端末内で処理されます。
- 🚫 **広告なし。トラッカーなし。永遠に。**

## 💾 ダウンロード

[**Releases**](https://github.com/SammyYohan/Reducto/releases/latest) ページから最新の APK を入手し、インストールしてください（この提供元からのインストールを許可するよう Android に求められます——Play ストア外のアプリでは普通のことです）。

> **Android 7.0 以降が必要。** インストール後はオフラインで動作します。

## 🆓 無料で試す

**3日間で10ファイル** — 自分のギャラリーでその違いを見るのに十分です。Reducto が役に立ったなら、Pro で無制限の圧縮を解放できます：月額、年額、または一回払いの**永久ライセンス**。お支払いはブラウザ内で安全に完了し（Stripe）、Reducto がカード情報を見ることは決してありません。
